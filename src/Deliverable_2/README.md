# TikTok-project-2026-group-7-deliverable-2-issue-7

## Goal
Analyze the data of platform users on TikTok by creating several plots.

## Data
- Main file: users.csv

## Requirements
- R
- Packages: dplyr, tidyverse, ggplot2
- Make installed

## Run steps
1. Set the terminal to the folder /src/Deliverable_2
2. Run the makefile (in folder /src/Deliverable_2) in the terminal with the command make

## Expected output
plot_1.png
plot_2.png
plot_3.png
plot_4.png

## Structure
- After running the makefile, the datasets should appear in /data/raw
- After running the makefile, the plot should appear in /src/Deliverable_2/plots
